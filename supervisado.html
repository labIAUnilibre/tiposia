¿Qué es el aprendizaje supervisado?

El aprendizaje supervisado es una forma de aprendizaje automático en la que un modelo se entrena con ejemplos que contienen datos de entrada y una respuesta conocida, llamada etiqueta. Durante el entrenamiento, el algoritmo ajusta sus parámetros para aprender la relación entre las entradas y las respuestas, con el objetivo de predecir resultados para datos nuevos.

Dos tareas comunes son la clasificación y la regresión. La clasificación predice categorías, como correo legítimo o spam; la regresión estima un valor numérico, como el precio probable de una vivienda. Para saber si el modelo generaliza, se evalúa con datos que no utilizó durante el entrenamiento y se seleccionan métricas adecuadas para el problema.
